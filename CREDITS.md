# Credits

BlindRadio for Android runs the same engine as [BlindRadio for desktop](https://git.serrebiradio.com/serrebi/blindradio): the same directories, gapless station changes with tuning hiss, song titles, time-shift, recording, the equalizer, and scheduled recordings. Same player, rebuilt for TalkBack on phones, tablets, and Android TV.

Questions and bug reports are welcome in the [SerrebiProjects Telegram group](https://t.me/SerrebiProjects). More serrebi projects: [projects.serrebiradio.com](https://projects.serrebiradio.com).
